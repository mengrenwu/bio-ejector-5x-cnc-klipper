# Project Documentation

## Overview

Bio-Ejector 5-Axis CNC with Klipper is a custom five-axis CNC project with an integrated air ejector, based on the Klipper-CNC motion control framework. The system is intended for automation in biomedical and precision manufacturing workflows.

## Development Status

This project is in early development. The repository currently contains Klipper configuration files, a GUI placeholder, and STL models for holders, structural components, a belt-driven linear stage, and a Z-axis stage. Documentation and source code will be updated as the design matures.

## Planned Features

- Five-axis motion support using Klipper-CNC.
- Real-time air ejector control.
- Modular kinematics configuration.
- Integration with host-side Python control scripts.
- Support for high-throughput biomedical workflows.
